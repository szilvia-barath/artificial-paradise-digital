## How to continue
`npm install && npm run dev` → http://localhost:5173. Floor plan + walls: `src/world/layout.js`. Texts (EN/HU): `src/i18n/*.json`. Works data and hang: `src/data/exhibition.json`. Furniture: `src/world/props.js`. Installations: `src/world/paradiseFactory.js`, `src/world/letItFlow.js`.
Regenerate images: `npm run images` (needs `reproductions/`, the room folders from Drive, and for the screens and in-situ views the original photos `DSC_*.JPG`, `_01_panorama.jpg` and `room_1/` from the private folder `artificial-paradise-photos`, copied into the repo root, where they are git-ignored; they were removed from the repository and its history). Regenerate wall textures: `npm run textures -- <folder of the Drive brick PNGs>` (also rebuilds the KTX2). Paradise Factory plant: `npm run plant -- <the .glb from Drive>`. Video loops: `scripts/make_videos.sh <folder of Drive videos>` (ffmpeg). River: `python3 scripts/make_river.py "PLANE javított.png" public/tex src/data/river.json` (NumPy + SciPy + Pillow). Real sizes from the artist: Let it Flow 4 × 7 m (the floor video's frame is 7 m long and spans the 4 m room; the plastic, registered to the frame, is about 4.7 × 1.6 m) and Paradise Factory 2.5 × 2.5 m (window wall to the far LED bar, channel's north end to the screen; `sx` in `paradiseFactory.js`). After changing any texture in `public/tex`: `node scripts/make_ktx2.mjs` writes the `.ktx2` versions the site loads (the `.webp` stay as fallback) and copies the Basis transcoder to `public/basis`.
Surface variation (anti-tiling, damp, pipe dirt, whitewash patches): `src/world/surface.js`; pipes register their dirt with `dirtAlong()` in `props.js`.
Text edition: `scripts/text-edition.mjs` writes `text/` and `text/hu/` on every build (and serves them in `npm run dev`); where a work is, in words: `src/world/route.js`. Accessibility checks: `npm run build && npm run preview`, then `npm run check:a11y` in a second terminal (Playwright needs its browser once: `npx playwright install chromium`). Hungarian strings to confirm: `python3 tests/tools/hu-confirm.py`. Loader background: `node scripts/make_loader_bg.mjs`.
